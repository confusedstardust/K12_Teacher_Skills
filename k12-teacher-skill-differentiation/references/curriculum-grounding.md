# 中国差异化教学的课程依据

## 基准

- 义务教育：使用《义务教育课程方案和课程标准（2022年版）》。
- 普通高中：使用《普通高中课程方案和语文等学科课程标准（2017年版2020年修订）》。
- 教材：使用教师实际采用的版本、册次、单元和课题，不默认人教版。

## 记录

```text
学段与年级：
学科：
课程标准名称与版本：
核心素养：
课程内容主题/任务群：
学业要求：
教材版本、册次、单元、课题：
依据状态：教师提供 / 官方核实 / 待核对
```

## 规则

1. 教师提供材料优先于模型记忆。
2. 网络核实时只优先采用教育部、中国政府网、省级教育行政部门等官方来源。
3. 不编造课标代码、教材页码、单元名称或逐字课标文本。
4. 三组保持同一课程依据；差异化改变入口和支持，不改变国家课程目标。
5. 中高考要求是附加约束，不能取代课程标准。

## 官方入口

- 教育部：[义务教育课程方案和课程标准（2022年版）](https://www.moe.gov.cn/srcsite/A26/s8001/202204/t20220420_619921.html)
- 教育部：[普通高中课程方案和学科课程标准（2017年版2020年修订）](https://www.moe.gov.cn/srcsite/A26/s8001/202006/t20200603_462199.html)
- 教育部：[中小学教材选用管理办法](https://www.moe.gov.cn/srcsite/A26/moe_714/202303/t20230320_1437577.html)
