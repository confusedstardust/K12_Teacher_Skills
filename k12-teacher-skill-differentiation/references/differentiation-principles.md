## 1. 三条学习路径

| 教师侧名称 | 学生页 | 设计目的 |
|---|---|---|
| 起点支持路径 | Group A | 补上紧邻先备、外化过程、逐步撤除支架 |
| 目标达成路径 | Group B | 按本课目标独立完成核心任务 |
| 深化迁移路径 | Group C | 在同一核心内容上概括、评价、设计或迁移 |

学生不知道这些教师侧名称。分组是本课暂定，可因一项任务表现而变化。

## 2. 支架选择

先定位障碍，再选一种主要支架：

| 障碍 | 首选支架 |
|---|---|
| 先备概念不稳 | 短诊断 + 具体/图示表征 + 回到原任务 |
| 读不懂任务 | 分句、关键词释义、图示流程，不改核心要求 |
| 不会组织表达 | 结构框架、证据表、句式起点，不预填答案 |
| 程序易错 | 步骤自检表、错误样例辨析，不给机械口诀 |
| 注意或执行功能 | 一次一条指令、可视化时间、检查点 |
| 缺少挑战 | 反例、开放条件、多方案比较、真实迁移 |

每题嵌入支架最多 1–2 个。词汇表、全页通用句式和教师侧追问不计入每题上限。

## 3. 形成性评价与换组

写清：

- 何时检查：如任务 1 后、独立练习 5 分钟后；
- 看什么证据：具体作品、表征、解释或错误；
- 什么触发调整：达到/未达到的可见标准；
- 如何调整：换任务单、加入临时支架、教师小组指导或进入拓展；
- 课后如何使用共同检测安排下一课。

禁止只写“巡视课堂、及时调整”。

## 4. 大班教学

- 三组使用相同任务顺序和共同口令，减少管理成本。
- 同一时间最多出现一个需要教师集中指导的组。
- 支架尽量印在任务单上，教师只处理关键卡点。
- 设计可由同桌互检的成功标准，但不让学生互相贴等级。
- 共同开始、共同收束，中段采用不同路径。

## 5. 合理便利

对随班就读或特殊需要学生，可调整字号、版式、输入方式、作答方式、时间、环境和辅助工具。只在有课程依据和学情证据时调整目标；不要把“少做、简单做”当作默认便利。

## 6. 失败模式

- 按一次考试永久分组；
- A 组只做机械基础题，失去核心情境和思维；
- C 组只是多做同类题；
- 支架直接包含答案；
- 三组任务被分别改写，导致核心要求漂移；
- 学生页出现“学困生、低层、简单版”等标签；
- 教师方案没有具体换组证据；
- 任务数量超过一课时或真实批改能力。
